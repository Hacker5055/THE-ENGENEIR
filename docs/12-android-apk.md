# تطبيق أندرويد (APK) · Android APK

> **بصراحة أولاً:** منصة المهندس تطبيق **Next.js بخادم** — المصادقة، محرّك الاختبارات، الدرجات والتقارير كلها تُحسب على الخادم. لذلك الـ APK ليس نسخة مستقلة تعمل دون إنترنت؛ هو **غلاف أصلي (native shell)** يفتح المنصة المستضافة بتجربة تطبيق حقيقية: أيقونة، ملء الشاشة، كوكيز من الطرف الأول، سحب للتحديث، زر رجوع، وموقع جغرافي للحضور.

## ما يوجد في المستودع

```
android/
├── settings.gradle.kts
├── build.gradle.kts
├── gradle.properties
└── app/
    ├── build.gradle.kts        ← AM_APP_URL تُحقن وقت البناء
    └── src/main/
        ├── AndroidManifest.xml
        ├── java/edu/almohandes/app/MainActivity.kt
        └── res/ (تخطيطات، سلاسل عربية/إنجليزية، أيقونة، إعداد أمان الشبكة)
.github/workflows/android-apk.yml   ← بناء APK على GitHub Actions
```

## كيف تحصل على ملف APK فعلي

المعاينة السحابية التي تعمل هنا **لا تحوي Android SDK**، لذا لا يمكن توليد ملف `.apk` داخلها. المسار العملي:

### 1. GitHub Actions (الموصى به — بلا تثبيت شيء)

1. افتح تبويب **Actions** في المستودع.
2. اختر **Android APK** ← **Run workflow**.
3. اكتب عنوان الخادم الذي يجب أن يفتحه التطبيق (افتراضياً `https://almohandes.edu`)، ثم شغّل.
4. بعد انتهاء التشغيل نزّل الأثر **`al-mohandes-debug-apk`** — يحتوي `app-debug.apk` جاهزاً للتثبيت على أي هاتف أندرويد 7.0+.

> تثبيت الـ debug APK يحتاج تفعيل «تثبيت من مصادر غير معروفة» على الهاتف، لأنه غير موقّع بمفتاح إصدار.

### 2. بناء موقَّع للإصدار

أضف هذه الأسرار إلى المستودع (Settings → Secrets and variables → Actions):

| السر | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | مخرجات `base64 -w0 release.keystore` |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة سر مخزن المفاتيح |
| `ANDROID_KEY_ALIAS` | اسم المفتاح |
| `ANDROID_KEY_PASSWORD` | كلمة سر المفتاح |

ثم شغّل الـ workflow نفسه؛ ينتج `al-mohandes-release-apk` موقّعاً وجاهزاً للنشر.

### 3. بناء محلي (Android Studio أو سطر الأوامر)

```bash
# يتطلب JDK 17 + Android SDK 35
gradle -p android assembleDebug -PAM_APP_URL="https://your-domain.example"
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

أو افتح مجلد `android/` مباشرة في Android Studio واضغط Run.

## كيف يعمل التطبيق

| القدرة | التفصيل |
|---|---|
| عنوان الخادم | يُحقن وقت البناء عبر `-PAM_APP_URL`، **ويمكن تغييره من داخل التطبيق** في أول تشغيل أو من شاشة الخطأ — فيعمل نفس الـ APK مع نسخة تجريبية أو إنتاجية |
| الجلسة | WebView بكوكيز طرف أول، فلا تعاني من حجب كوكيز الطرف الثالث الذي يحدث داخل إطارات المعاينة |
| الحضور | يطلب إذن الموقع عند أول استخدام ويُمرّره للصفحة (نفس منطق النطاق الجغرافي على الخادم) |
| الملفات | رفع ملفات من الجهاز (onShowFileChooser) وتنزيل عبر DownloadManager |
| التنقل | زر الرجوع يتصرف كتطبيق أصلي (رجوع داخل الصفحات ثم إغلاق)، وأي رابط خارجي يُفتح في المتصفح |
| الشبكة | شاشة خطأ واضحة مع «إعادة المحاولة» و«تغيير عنوان الخادم» بدل شاشة بيضاء |

## القيود المعلنة

- التطبيق **يحتاج اتصالاً بالخادم**؛ لا يعمل دون إنترنت (البيانات كلها خادمية).
- `usesCleartextTraffic` مُفعّل لأن الخوادم التجريبية قد تكون `http`؛ في الإنتاج استخدم `https` فقط.
- لم يُختبر على متجر Google Play (لا حساب نشر، ولا توقيع إنتاجي في هذا المستودع).
- الشاشة تُعرض كما هي في الويب؛ لا يوجد تصميم أصلي مخصص لكل صفحة — وهذا قرار مقصود: مصدر واحد للكود، ولا تباعد بين الويب والتطبيق.
